TOOLS

수업 자료 정리에 필요한 기능

🗂️

파일 관리

파일명 일괄 변경, 중복 검사, 검색과 파일 목록 내보내기를 지원합니다.

🖼️

이미지 처리

JPG, PNG, WebP 형식 변환과 비율을 유지한 크기 조정을 수행합니다.

📄

PDF 도구

병합, 페이지 추출, 분할, 회전, 삭제와 순서 변경을 처리합니다.

📊

Excel 도구

XLSX 병합·분할·정리, CSV 변환과 명단 그룹화를 제공합니다.

🔍

개인정보 형식 검사

문서에서 주민등록번호, 휴대전화번호, 이메일 형식을 찾아 마스킹합니다.

⚙️

업무 자동화

반복 작업을 템플릿으로 저장하고 최근 실행 기록을 관리합니다.

LOCAL FIRST

파일은 컴퓨터 안에서 처리됩니다.

이미지, PDF, Excel과 개인정보 검사는 로컬에서 실행됩니다. 파일 본문을 서버로 업로드하거나 원격 분석하는 기능이 없습니다. 문서 PDF 변환은 컴퓨터에 설치된 LibreOffice를 사용합니다.
