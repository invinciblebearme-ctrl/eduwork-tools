# EduWork Tools

Windows용 교육 업무 파일 도구입니다. 문서 변환과 개인정보 검사는 파일을 로컬에서 처리하며 네트워크로 전송하지 않습니다.

## License

라이선스는 아직 지정되지 않았으며 별도 라이선스 파일도 없습니다. 이 저장소의 공개가 코드 재사용·재배포 허가를 뜻하지는 않습니다.

## 제공 기능

- Phase 2: 파일 이름 변경, 중복 검사, 파일 목록 내보내기와 검색, 어휘 이미지 점검, 확장자별 사본 정리
- Phase 3: JPG/JPEG, PNG, WebP 변환·크기 조정
- Phase 4: PDF 병합, 페이지 추출·개별 분할, 홀수/짝수 추출, 회전·삭제·순서 변경, 이미지 PDF 생성
- Phase 5: XLSX 병합·분할·정리·CSV 변환 및 학년/반 명단 그룹화·선택 열 중복 집계/정렬
- Phase 6: DOCX/XLSX/PPTX 및 LibreOffice가 실제 처리하는 일부 HWP의 PDF 변환, TXT/CSV/XLSX/PDF/DOCX/PPTX 개인정보 형식 검사

## 문서 PDF 변환

DOCX, XLSX, PPTX 변환은 로컬에 설치된 LibreOffice `soffice` 실행 파일만 사용합니다. PATH 또는 일반적인 Windows 설치 경로에서 찾으며, 없으면 설치 필요 오류를 표시합니다. 이 앱은 LibreOffice를 설치하거나 내려받지 않습니다. 변환은 격리된 임시 출력 폴더와 프로필에서 실행하고 최대 3분, 입력 250 MiB로 제한합니다. 출력 파일이 이미 있으면 덮어쓰지 않습니다.

HWP는 LibreOffice에 해당 가져오기 필터가 설치되어 있고 문서 기능과 버전이 호환될 때만 변환됩니다. HWP 변환 성공을 보장하지 않습니다. HWPX는 지원하지 않으며 한컴오피스에서 PDF로 내보내야 합니다.

## 개인정보 검사 제한

주민등록번호, 한국 휴대전화번호, 이메일의 기본 형식을 로컬 Rust 정규식으로 찾습니다. 선택적으로 Rust `regex` 문법(lookaround 미지원)의 라벨/정규식을 추가할 수 있습니다. 마스킹된 값만 화면 및 UTF-8 BOM CSV에 표시·저장합니다. 이 검사는 형식 일치 검사이며 오탐과 누락이 있을 수 있어 완전한 개인정보 감사가 아닙니다.

PDF는 `lopdf`로 선택 가능한 텍스트만 검사합니다. OCR을 하지 않으므로 스캔 PDF와 이미지 내부 글자는 검사되지 않습니다. 암호화·손상·지원되지 않는 각 파일은 오류 목록으로 보고하고 나머지 검사를 계속합니다. 심볼릭 링크는 건너뛰며 파일 수와 총 읽기/압축 해제 크기를 제한합니다.

## 실행

요구 환경: Windows 10/11, Node.js/npm, Rust/Cargo, Microsoft C++ Build Tools, WebView2. PDF 문서 변환에는 별도 로컬 LibreOffice 설치가 필요합니다.

```powershell
npm install
npm run tauri:dev
```

```powershell
cd src-tauri
cargo test --lib
cargo check
cargo fmt --check
```


## Phase 7 · 업무 자동화

업무 자동화 메뉴에서 이름 있는 템플릿을 저장·불러오기·갱신·삭제하고 실행 기록을 확인합니다. 실행 때마다 네이티브 대화상자로 입력 폴더와 출력 위치를 지정합니다.

- 이미지 폴더 → 기존 Rust 이미지 모듈로 JPG/JPEG/PNG/WebP 크기 조정(너비, 비율 유지) 및 형식 변환. JPEG/WebP 품질 85. 파일별 오류 후 나머지 계속 처리.
- PDF 폴더 → 파일명 사전순(숫자 자연 정렬 아님, 대소문자 구분)으로 기존 PDF 모듈 병합. 손상·암호화 입력이 있으면 전체 실패.
- XLSX 폴더 → 동일 시트 이름·머리글의 단일 시트 2~50개 병합 후 공백 정리·중복/빈 행 제거. 선택한 열로 그룹화 가능. 기존 Excel 루틴을 사용하며 수식·서식 보존이 아닌 문자열 값 처리. 기본 정리본과 값순 group-001 형식의 그룹 파일 생성.

폴더 바로 아래만 탐색합니다. 최대 50파일, 파일당 100 MiB, 총 250 MiB, 폴더 항목 최대 10,000개입니다. 심볼릭 링크를 건너뛰며 링크 경로는 거부합니다. 원본을 수정하지 않고 기존 출력은 덮어쓰지 않습니다. 이미지 이름 충돌은 번호를 붙이고 PDF/Excel 충돌은 오류입니다. 그룹은 최대 100개입니다.

템플릿 최대 100개와 최근 실행 200회를 Tauri 앱 로컬 데이터 디렉터리(`%LOCALAPPDATA%/kr.eduwork.tools/workflows.json`)에 저장합니다. 시작/종료 UTC 시각, 입력 파일 수, 입력/출력 경로, 성공 여부, 오류 및 건너뛴 링크 수를 기록합니다. 저장 파일에는 로컬 경로가 포함됩니다. 8 MiB 제한, 같은 디렉터리 임시 파일과 동기화 후 원자적 교체를 사용합니다. JSON 손상 시 원문을 보존하고 오류를 표시하므로 해당 파일을 백업·복구해야 합니다. 실행 시작 기록이 남은 채 앱이 종료되면 '완료 기록 없음'으로 표시됩니다. 실행 후 기록 저장 실패는 출력 경로와 함께 오류로 보고합니다.

작업 중 취소와 백분율 진행률은 제공하지 않습니다. PDF/Excel 실패 시 전체 입력을 건너뛰지 않으며, 여러 출력 중 일부가 이미 저장된 경우 실행 기록의 출력 목록에 남습니다. 예약 실행, 임의 단계 편집, 다중 시트 명단 정리 및 다른 모듈 연결은 **준비 중**입니다.

## Phase 8 · 최종 강화와 릴리스 준비

출력은 완성된 같은 폴더 임시 파일을 동기화한 뒤 덮어쓰기 없이 원자적으로 게시합니다. 출력 종류·확장자와 템플릿 필드를 실행 전에 검증하고, 실패 기록 및 최근 200회 보존을 테스트합니다. 여러 출력 중 일부 완료는 기록에서 별도로 표시합니다. 취소와 백분율 진행률은 여전히 제공하지 않습니다.

[한국어 릴리스 준비 체크리스트와 Windows 수동 회귀 절차](docs/RELEASE_READINESS.md)에 런타임 의존성, 개인정보 처리, 로컬 저장 경로, 백업/복원 및 남은 제한을 정리했습니다. Rust 테스트 61개와 Cargo/npm 검증이 통과했습니다. Windows v0.1.0 산출물은 `release-artifacts/v0.1.0/`에 있습니다. NSIS 설치·실행·제거는 검증됐고, MSI는 빌드·압축 해제 및 앱 실행까지 확인했지만 관리자 권한 설치는 미검증입니다. 세 바이너리 모두 서명되지 않았고 LibreOffice 문서 변환 경로도 미검증입니다.
