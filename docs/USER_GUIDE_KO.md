# EduWork Tools 사용자 안내서

## 1. 시작하기

EduWork Tools는 Windows 10/11에서 파일을 로컬 처리하는 교사용 도구입니다. 파일 내용을 원격 서버로 보내지 않습니다. 입력 원본은 기본적으로 보존하고, 생성 결과는 사용자가 고른 별도 경로에 저장합니다. 작업 전에 원본을 별도 백업하는 것을 권장합니다.

### 실행

개발 환경에서는 프로젝트 루트에서 다음을 실행합니다.

```powershell
npm install
npm run tauri:dev
```

[v0.1.0 Windows 설치 파일과 실행 파일은 GitHub Release](https://github.com/invinciblebearme-ctrl/eduwork-tools/releases/tag/v0.1.0)에서 받을 수 있습니다. NSIS 설치 파일은 임시 위치에서 설치·실행·제거를 검증했습니다. MSI는 만들어졌지만 모든 사용자 설치에는 관리자 권한이 필요하며 실제 설치·제거는 검증되지 않았습니다. 설치 파일은 서명되지 않았습니다.

## 2. 공통 사용 순서

1. 왼쪽 메뉴에서 작업 모듈을 엽니다.
2. 파일/폴더 선택 버튼으로 시험 파일 또는 복사본을 지정합니다.
3. 출력 폴더나 저장 파일을 선택합니다.
4. 옵션과 미리보기를 확인합니다.
5. 실행 후 표시된 결과와 출력 파일을 확인합니다.
6. 오류가 있으면 원본을 보존한 채 입력·출력 선택을 다시 확인합니다.

기존 파일 덮어쓰기가 거부되면 다른 출력 이름/폴더를 선택하세요. 자동화 기록에는 로컬 경로가 포함될 수 있으므로 공유 전에 확인하세요.

## 3. 모듈별 기능

### PDF 도구

PDF 병합, 페이지 범위 추출, 페이지별 분할, 이미지에서 PDF 만들기를 제공합니다. 추가로 홀수/짝수 페이지 추출, 페이지 회전, 삭제, 순서 변경 기능이 구현돼 있습니다. 범위는 화면 안내 형식에 맞춰 입력하고 결과 PDF의 페이지 수와 순서를 확인하세요. 손상되거나 암호화된 파일은 처리에 실패할 수 있습니다.

PDF 내부 이미지 추출, 페이지 이미지 렌더링, 이미지 다운샘플링을 포함한 고급 압축은 현재 지원 범위로 확인되지 않았습니다.

### Excel 도구

XLSX 병합·분할·정리·CSV 변환과 학생 명단 처리를 제공합니다. 명단 작업에는 학년/반 그룹화, 선택 열 기준 중복 집계, 지정 열 정렬 옵션이 있습니다. 입력 열 번호는 화면에 안내된 기준으로 지정하세요.

중요: 처리 결과는 셀 값을 중심으로 새 워크북에 기록합니다. 원본 수식·서식·병합 셀·차트·매크로·데이터 유효성 검사의 보존을 보장하지 않습니다. 원본을 유지하고 복사본으로 먼저 시험하세요. 다중 열 우선순위 정렬은 지원하지 않습니다.

### 이미지 도구

JPG/JPEG, PNG, WebP 변환, 크기 조정, 비율 유지 또는 지정 크기 처리와 정사각형 여백 옵션을 제공합니다. 출력 형식과 품질을 선택하고, 변환 결과와 파일 크기를 확인하세요. 일부 입력 오류가 있어도 나머지 파일 처리를 계속하는 배치 동작이 적용될 수 있습니다.

### 파일 관리

이름 변경 미리보기/적용, 중복 파일 검사, 파일 목록 CSV/XLSX 내보내기, 검색, 어휘 이미지 점검, 확장자별 사본 정리를 제공합니다. 확장자별 정리는 파일을 이동하거나 삭제하지 않고 별도 출력 폴더에 복사합니다. 충돌이 있으면 덮어쓰지 않고 전체 작업을 거부합니다. 이름 변경은 적용 전 전체 계획과 충돌 여부를 검토하세요.

### 문서 변환

DOCX/XLSX/PPTX의 PDF 변환은 로컬 LibreOffice `soffice` 설치에 의존합니다. 앱은 LibreOffice를 설치하거나 내려받지 않습니다. HWP는 LibreOffice의 가져오기 필터 및 파일 호환성에 따라 일부만 가능하며 성공을 보장하지 않습니다. HWPX는 미지원입니다.

### 개인정보 점검

주민등록번호, 한국 휴대전화번호, 이메일 형식과 사용자가 지정한 정규식을 로컬에서 검색하고 마스킹 결과를 표시/CSV로 내보냅니다. TXT/CSV/XLSX/PDF/DOCX/PPTX 등 지원 형식과 패턴에 제한됩니다. 스캔 PDF·이미지 문자는 OCR하지 않으며 HWP/HWPX 지원 및 완전한 개인정보 감사를 보장하지 않습니다. 오탐과 누락 가능성이 있으므로 결과를 별도 검토하세요.

### 업무 자동화

현재 제공되는 템플릿은 이미지 변환, 파일명순 PDF 병합, 단일 시트 XLSX 정리/그룹화입니다. 템플릿과 최근 실행 기록은 앱 로컬 데이터에 저장됩니다. 기록은 경로를 포함할 수 있습니다. 예약 실행, 실행 취소, 백분율 진행률, 임의 단계 편집은 지원하지 않습니다. 여러 출력 중 일부만 완료될 수 있으므로 기록의 완료 출력 목록을 확인하세요.

### 설정 및 백업

설정 메뉴의 일부 안내는 메모/설명 용도이며 시스템 설정을 자동 변경하지 않습니다. 워크플로 데이터의 백업·복원은 자동 기능이 아니라 수동 파일 복사 절차입니다. 구체 경로와 복원 순서는 `docs/RELEASE_READINESS.md`를 참고하세요.

## 4. 개인정보와 파일 안전

- 민감한 파일은 원본을 보존하고 복사본으로 시험합니다.
- 공유 전 출력 파일, CSV, 로그와 경로에 개인·학생 정보가 포함되지 않았는지 확인합니다.
- 파일 검사/개인정보 점검은 패턴과 형식에 제한이 있으므로, 결과가 없다고 해서 정보가 전혀 없다고 단정하지 마세요.
- 워크플로 기록 파일을 교체/복원할 때는 앱을 종료하고 현재 파일도 먼저 별도 백업하세요.
- 출력 충돌이나 오류가 발생하면 대상 폴더를 확인하고, 사용자가 직접 결정하기 전에는 기존 파일을 삭제하지 마세요.

## 5. 지원 범위와 검증 상태

전체 자동 검증 절차와 실제 회귀 결과, 미완료 릴리스 게이트는 `docs/RELEASE_READINESS.md`에 기록합니다. 최신 자동 검사에서는 Rust 테스트 61개, Cargo 검사/포맷, 프런트엔드 타입 검사/빌드가 통과했습니다. 주요 기능은 실제 UI 회귀를 거쳤고 NSIS 설치 파일은 설치·실행·제거를 확인했습니다. MSI의 관리자 권한 설치와 LibreOffice 기반 문서 변환 경로는 미검증이며, 이 안내서는 모든 기능의 완전한 지원을 보장하지 않습니다.
